# Todo List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the greeting practice app with a single-screen todo list — add, tick, delete — served HTML-over-the-wire from axum with Askama templates and htmx 4.

**Architecture:** One in-memory `Arc<RwLock<TodoList>>` behind axum's `State`. `GET /` renders a full page; every mutation is a `POST` that returns an HTML fragment, which htmx swaps in. Two swap targets — `#todo-panel` for create, `#todo-list` for toggle and delete — so the add input clears itself on the server's response without any client-side JS.

**Tech Stack:** Rust edition 2024, axum 0.8.9, askama 0.16.0, tokio 1.52.4, tower-http 0.7.0, serde 1.0.228, tracing 0.1.44 / tracing-subscriber 0.3.23, htmx 4.0.0 (CDN), tower 0.5.3 (dev-only).

**Spec:** `docs/superpowers/specs/2026-10-08-todo-list-design.md`

## Global Constraints

- Every colour and every `font-family` in CSS must be a named `var(--token)` reference. No inline OKLCH, no inline hex, no inline `rgb()`. If a value is needed that isn't a token, add the token first.
- CSS colours are OKLCH only. No `#000`, no `#fff`, no `hsl()`, no flat zero-chroma greys.
- Exactly one accent: `--color-accent`. It is never used as a surface fill.
- Never `transition-all`. Always name the transitioned properties and always pass a named easing. Never browser-default `ease`, never a bouncy/overshoot curve on UI state.
- Every interactive element styles all eight states: default, hover, `:focus-visible`, active, disabled, loading, error, success. Hover rules live inside `@media (hover: hover) and (pointer: fine)`.
- Focus rings use `:focus-visible`, appear instantly, and are never transitioned. Never write `outline: none` without a replacement.
- Text input `border-width` is constant (1px) across every state. State changes go to `background-color`, `outline`, or `box-shadow` — never `border-width`.
- Touch targets are at least 44×44 CSS px.
- `prefers-reduced-motion: reduce` collapses all motion to a ≤150ms opacity crossfade.
- Root `overflow-x: clip` on both `html` and `body`. Never `overflow-x: hidden`.
- No `100vw` widths. Use `width: 100%` with padding.
- Clickable text is `white-space: nowrap` — no affordance wraps to two lines at 320 / 375 / 414 / 768 px.
- No client-side JS anywhere in this app. No JSON API. htmx only.
- htmx is pinned to exactly `4.0.0`. Do not switch to a `latest` tag.
- Every element that triggers a request carries its own `hx-post`, `hx-target`, and `hx-swap`. Nothing relies on htmx attribute inheritance.
- Todo text is escaped by Askama's default HTML escaping. Never add `|safe` to a todo text field.
- No new runtime dependencies. `tower` is the only addition and it is `[dev-dependencies]` only.

use std::sync::{Arc, RwLock};

use askama::Template;
use axum::{
    http::StatusCode,
    response::{Html, IntoResponse, Response},

// --- Error handling ---
// One error type every handler returns. Converts any Askama render failure
// into a clean 500 instead of panicking the request.

pub struct AppError(askama::Error);

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        tracing::error!(error = ?self.0, "template render failed");
        (StatusCode::INTERNAL_SERVER_ERROR, "something went wrong").into_response()
    }
}

impl From<askama::Error> for AppError {
    fn from(err: askama::Error) -> Self {
        AppError(err)
    }
}

// --- Model ---

pub struct Todo {
    pub id: u64,
    pub text: String,
    pub done: bool,
}

/// The vec and the id counter share one lock, so the counter can never
/// drift from the data it counts.
#[derive(Default)]
pub struct TodoList {
    items: Vec<Todo>,
    next_id: u64,
}

impl TodoList {
    /// Trims, and returns false-ish nothing when the text is blank.
    /// Blank input is a no-op by design — `<input required>` already
    /// blocks it in the browser.
    pub fn add(&mut self, text: &str) -> bool {
        let text = text.trim();
        if text.is_empty() {
            return false;
        }
        self.next_id += 1;
        let id = self.next_id;
        self.items.push(Todo {
            id,
            text: text.to_owned(),
            done: false,
        });
        true
    }

    /// Returns false if no todo has this id.
    pub fn toggle(&mut self, id: u64) -> bool {
        match self.items.iter_mut().find(|t| t.id == id) {
            Some(todo) => {
                todo.done = !todo.done;
                true
            }
            None => false,
        }
    }

    /// Returns false if no todo has this id.
    pub fn delete(&mut self, id: u64) -> bool {
        match self.items.iter().position(|t| t.id == id) {
            Some(index) => {
                self.items.remove(index);
                true
            }
            None => false,
        }
    }

    /// Active todos first, completed after. `sort_by_key` is stable, so
    /// insertion order survives inside each group.
    pub fn sorted(&self) -> Vec<&Todo> {
        let mut items: Vec<&Todo> = self.items.iter().collect();
        items.sort_by_key(|t| t.done);
        items
    }

    #[cfg(test)]
    fn len(&self) -> usize {
        self.items.len()
    }
}

pub type TodoStore = Arc<RwLock<TodoList>>;

pub fn new_store() -> TodoStore {
    Arc::new(RwLock::new(TodoList::default()))
}

```rust
/// Locks the store, applies `mutate`, and renders the list fragment.
/// `mutate` returns false when the id was not found, which becomes a 404
/// whose body is still the current list.
fn with_list<F>(store: &TodoStore, mutate: F) -> Result<Response, AppError>
where
    F: FnOnce(&mut TodoList) -> bool,
{
    let (found, todos) = {
        let mut list = store.write().expect("lock poisoned");
        let found = mutate(&mut list);
        (found, list.sorted())
    };

    let body = TodoListTemplate { todos }.render()?;
    let status = if found {
        StatusCode::OK
    } else {
        StatusCode::NOT_FOUND
    };
    Ok((status, Html(body)).into_response())
}

async fn toggle(
    State(store): State<TodoStore>,
    axum::extract::Path(id): axum::extract::Path<u64>,
) -> Result<Response, AppError> {
    with_list(&store, |list| list.toggle(id))
}

async fn delete(
    State(store): State<TodoStore>,
    axum::extract::Path(id): axum::extract::Path<u64>,
) -> Result<Response, AppError> {
    with_list(&store, |list| list.delete(id))
}
```
